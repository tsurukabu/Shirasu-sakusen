# しらす式 キングダム覇道 完凸シュミレーター

## GitHub Pagesで公開する方法
1. GitHubで新しいリポジトリを作成します（例: `shirasu-kantotsu`）。
2. このZIP内の `index.html` をリポジトリ直下にアップロードします。
3. GitHubのリポジトリで **Settings → Pages** を開きます。
4. **Build and deployment → Source** を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/(root)` にして **Save**。
6. 数分後に表示されるGitHub PagesのURLをLINE、Discord、YouTube概要欄などで共有できます。

JavaScriptはindex.html内に入っているため、追加ファイルや外部ライブラリは不要です。
